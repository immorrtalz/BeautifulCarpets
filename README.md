This mod adds beautiful carpets, inspired by [doctor4t](https://modrinth.com/user/RAT)'s ["The Last Voyage of the Harpy Express"](https://modrinth.com/mod/wathe) - redrawn and recolored.

<br>

<img src="https://github.com/immorrtalz/BeautifulCarpets/raw/neoforge_1.21.1/promo/screenshots/1.png" alt="All blocks"/>

## ✨ Blocks
- 16 colors moquettes - as carpets and blocks (so could be used with something like Copycats):
  1. red
  2. orange
  3. yellow
  4. olive
  5. green
  6. seagreen
  7. emerald
  8. aquamarine
  9. blue
  10. cobaltblue
  11. midnight
  12. violet
  13. purple
  14. orchid
  15. black
  16. gray
